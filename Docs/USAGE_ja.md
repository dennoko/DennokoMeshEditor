# DenMeshEditor 使い方

VRChat アバター改変向けの、非破壊メッシュ編集ツールです。
頂点を掴んで動かすだけで、服の食い込みや体型を調整できます。元のメッシュファイルは書き換えません。

## 必要環境

- Unity 2022.3.22f1 以降
- VRChat SDK
- **NDMF (nadena.dev.ndmf)** — 必須

---

## 基本的な使い方

### 1. コンポーネントを付ける

ヒエラルキー上で編集したいメッシュ（SkinnedMeshRenderer / MeshRenderer）を持つオブジェクトを右クリックし、
`dennokoworks > Den Mesh Editor` を選択します（または Inspector の `Add Component` から追加します）。

- **Renderer を持つオブジェクトに右クリックから追加した場合：**
  そのメッシュが自動的に編集対象として登録され、**即座に編集モードが有効化**されます。
- **Renderer のないオブジェクトに追加した場合：**
  コンポーネントのみが追加されます。Inspector の「対象を追加」から編集したい Renderer を指定してください。

複数のメッシュをまとめて編集したい場合は、Inspector の「対象を追加」から Renderer を追加してください。
服と素体を同時に登録しておくと、境界をまたいで一緒に馴染ませられます。

### 2. 編集する

Inspector の **「編集」** ボタンを押すと、シーンビューが編集モードになります。

| 操作 | 動作 |
| --- | --- |
| メッシュ上の頂点をクリック | **見えている**頂点のうち、クリック位置に最も近いものを選択（黄色い点が候補、青い円が影響範囲） |
| 移動ハンドルをドラッグ | 選択位置を中心に、影響範囲内の頂点が減衰しながら一緒に動く |
| **ハンドルを掴んだままマウスホイール** | **影響範囲の半径を変更（上で拡大、下で縮小）** |
| Esc | 選択解除。もう一度押すと編集終了 |
| 別のオブジェクトを選択 | 編集終了 |

シーンビュー左上のパネルで、半径・減衰・ミラーをその場で変更できます。

### 頂点の選択について

**裏側に隠れた頂点は選択されません。**手前の面に遮られている頂点は候補から除外され、
実際に見えている頂点のうちクリック位置に最も近いものが選ばれます。

片面でモデリングされたスカートや髪も、表示されていれば裏側から選択できます
（法線の向きではなく、実際に遮られているかどうかで判定しています）。

> **注意：** 遮蔽物として見るのは**編集対象に登録した Renderer だけ**です。
> たとえば素体だけを登録して服を登録していない場合、服に隠れた素体の頂点も選択できてしまいます。
> 服も編集対象に追加すれば解決します。

なお、選択した後の**影響範囲には裏側の頂点も含まれます**。薄い布などを動かしたときに
表と裏が一緒に動くのは意図した挙動です。

### やり直し（Undo）

**ハンドルを掴んで動かす 1 動作が Undo 1 回分**です。Ctrl+Z を押すと、直前のドラッグだけが取り消されます。

ハンドルを掴んでいる間にホイールで変えた半径も同じ 1 回に含まれるので、「動かして半径も調整した」操作はまとめて元に戻ります。

### ハンドル操作中の半径変更

ハンドルを掴んだままホイールを回すと、影響範囲を広げたり狭めたりできます。
**掴んだだけで、まだ動かしていない状態でも変更できます。**動かす前に「どこまで巻き込むか」を決めてから
ドラッグに入れますし、動かした後なら**動かした状態のまま**調整できます。
結果はその場でメッシュに反映されるので、「どこまで馴染ませるか」を見ながら決められます。

ホイールは 1 目盛りごとに一定の割合で変化するため、半径が小さいときは細かく、大きいときは大きく動きます。
半径を狭めると、範囲から外れた頂点はドラッグ開始時の位置に戻ります。

変更した半径はマウスを離した時点で確定し、次回以降のブラシ設定として保持されます。
なおホイールが半径変更になるのは**ハンドルを掴んでいる間だけ**です。手を離していれば、通常どおりシーンビューのズームになります。

### 3. そのままアップロード

保存操作は不要です。編集結果はコンポーネントに保存され、アップロード時に自動で反映されます。

## ブラシ設定

### 半径

影響範囲の広さ（ワールド単位、メートル）です。シーンビューに円で表示されます。

### 減衰

中心から離れるにつれて動きが弱まる度合いです。

| 種類 | 特徴 |
| --- | --- |
| スムーズ | 端がなめらか。通常はこれ |
| 直線 | 一定の割合で減衰 |
| シャープ | 中心付近だけ強く動く |
| 一定 | 範囲内を均等に動かす（減衰なし） |

---

## ミラー編集

**ミラーが有効な間に行った操作だけ**が左右対称に適用されます。
後から一括でミラーを掛け直す機能ではありません。

### 仕組み

編集操作そのものを反転させます。中心座標を反対側に移し、**変位の向きも反転**させたうえで、
反対側でも同じ半径・減衰で編集します。

このため **左右対称なトポロジは不要**です。左右で頂点数や配置が違うメッシュ、
片側にしかパーツがないモデルでも正しく動作します。対称頂点を探す許容誤差の設定も要りません。

基準となる対称面は、アバタールートのローカル空間の中心面です。

### 注意

中心線のごく近くを編集した場合、ミラーは適用されません（左右の影響範囲が重なって
二重に動いてしまうのを防ぐためです）。中心線付近は通常の編集として扱われます。

## ベイク

編集結果を適用したメッシュを、ファイルとして書き出せます。

- 保存先は **元メッシュと同じフォルダ**
- 名前は元メッシュ名に **`_edited`** を付けたもの（既に付いている場合は追加しません）
- 同名がある場合は末尾に連番（`Body_edited 1`, `Body_edited 2` …）

### シェイプキーとして追加

チェックを入れてベイクすると、元の形状はそのままに、
**編集分を新しいシェイプキーとして追加**したメッシュが出力されます。

### 注意

ベイクは**ファイルを書き出すだけ**です。シーン内の Renderer は自動で差し替えません。
差し替えたい場合は、出力されたメッシュを手動で設定してください（ベイク後に自動選択されます）。

## 仕様と制限

### できること

- 頂点の移動（プロポーショナル編集）
- 任意の軸でのミラー編集
- 複数メッシュの同時編集
- NDMF プレビューへのリアルタイム反映
- ベイク（メッシュ / シェイプキー）

### できないこと（意図的に対応していません）

- 頂点・面の追加や削除、押し出しなどのトポロジ編集
- UV / 法線 / ウェイトの編集
- 矩形での範囲選択（クリック選択のみ）

### 法線について

**法線・接線は再計算しません。** 大きく変形させると陰影が形状に追従しませんが、
再計算するとシェーディングが変わってしまうため、意図的にこの仕様にしています。

### 頂点インデックスへの依存について

本ツールはシェイプキーと同様に、**「元のメッシュの頂点インデックス（頂点番号）」に対して差分（デルタ）を保存・適用する仕組み**になっています。そのため、以下の点にご注意ください。

- **FBX の再インポート / 再エクスポート：**
  DCCツール（Blender等）からメッシュを再エクスポートした際に頂点数や頂点順序が変化すると、保存されていた編集位置とズレが生じます。
- **別メッシュへの差し替え：**
  編集データを保持したまま Renderer のメッシュを別のモデルに差し替えても、編集内容は引き継がれません。
- **誤変形の安全対策：**
  メッシュの差し替えや再インポート等で頂点数が編集時と異なっている場合、誤った頂点が変形してモデルが崩れるのを防ぐため、**編集の適用は自動的に安全にスキップ**され、Inspector およびログに警告が表示されます。

### 他ツールとの関係

編集の基準となる形状は NDMF プレビューから取得しているため、
Modular Avatar の Scale Adjuster など、他のツールによる変形を反映した状態で編集できます。

ビルド時は Transforming フェーズで処理するため、
メッシュの頂点数を変更・最適化する Avatar Optimizer (AAO) よりも先に適用され、安全に共存できます。

## トラブルシューティング

### 「NDMF プレビュー未取得」と表示される

NDMF のプレビューが無効になっているか、まだ生成されていません。
この状態でも編集はできますが、**他ツールの影響が反映されていない形状**を編集することになります。

Unity のツールバーから NDMF のプレビューが有効になっているか確認してください。

### 「頂点数が編集時と異なります」と表示される

元メッシュが差し替わったか、FBX の再インポートで頂点の順序が変わっています。
この状態では編集が適用されません（誤った頂点が動くのを防ぐためです）。

編集内容は頂点番号を基準に保存しているため、この場合は編集をやり直す必要があります。
Inspector の「すべての編集をクリア」で一度リセットしてください。

### 編集が反映されない

- コンポーネントが有効になっているか
- 対象 Renderer が設定されているか
- NDMF のプレビューが有効になっているか

を確認してください。
